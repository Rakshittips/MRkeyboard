- 📐 **Size Controls**: Customize keyboard height, bottom spacing, side padding, and corner roundness.

## 📲 Installation & Setup

1. **Download APK**: Grab the latest APK from [devuploads.com/xrkjk49pm6yw](https://devuploads.com/xrkjk49pm6yw).
2. **Allow Installation**: Enable *"Install unknown apps"* for your browser if prompted.
3. **Enable Keyboard**: Open **MRkeyboard** and tap **Open** to turn on the keyboard in Android Settings.
4. **Select Input Method**: Tap **Select** and choose **MRkeyboard** as your active keyboard.
5. **Permissions**: Grant microphone access for voice typing.
6. **(Optional) iOS Emoji**: Download the `.ttf` emoji font, then tap *Pick emoji font file (.ttf)* in MRkeyboard settings.
